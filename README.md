## 📖 Overview
**Swiss Army Recon Tool** is a modular information-gathering application developed as a 3rd-year Engineering project. 

### 🚀 Key Capabilities
| Phase | Feature | Purpose |
| :--- | :--- | :--- |
| Phase 1 | DNS Enumeration | Discovers hidden subdomains. |
| Phase 2 | Multi-threaded Scan | Rapidly identifies open TCP ports. |
| Phase 3 | Banner Grabbing | Extracts service versions. |
| Phase 4 | HTTP Security Audit | Checks for missing security headers. |
